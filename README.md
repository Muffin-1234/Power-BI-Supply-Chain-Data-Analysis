# Power-BI-Supply-Chain-Data-Analysis
This project shows the distribution of various products in different locations in India and how it affects profitability and revenue

## Features
- Revenue distribution by location
- Order quantities by transportation
- Average cost of shipping per transportation mode
- Total amount per product
- Revenue per product

## Tools used
Power BI
